### ⟡ How I build

- **Offline-first.** Study, tracking and exams all work with no signal. The app never waits for a server.
- **One engine, many apps.** Passpip is a monorepo where each country is a separate store app built from the same codebase.
- **Pure, tested logic.** Scoring, readiness, streaks and spaced repetition live in a plain TypeScript package with the clock passed in, and they're covered by unit tests.
- **Design systems, not one-off styles.** Theme tokens, light and dark mode, one configurable component per role, and touch targets of 48 dp or more.
- **Built for every reader.** Four languages, including right-to-left Arabic, with system font scaling respected.
